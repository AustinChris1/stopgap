# Money, consumer, and filing workflows for the Open Agent Hackathon

Scope checked on 2026-10-20: CFPB consumer complaints plus enforcement actions; FEMA OpenFEMA disaster and public-assistance datasets; USASpending or Grants.gov closeout/reporting; FCC robocall or consumer-complaint data; NHTSA complaints and recalls at api.nhtsa.gov. Build window is 22–27 October 2026. Submissions close 27 October 2026 23:45 UTC. The survivor must be a cited draft for a named person, built in Cursor on Zetaris plus Meterless, from REST JSON or CSV/Parquet that was actually opened, joined on an identifier, with a second run changed by stored memory. No local NVIDIA model.

## Which of the five source directions is ready to join on an identifier over plain HTTP?

### Takeaway

Only OpenFEMA Public Assistance is ready for a Zetaris join: two plain-HTTP JSON endpoints returned rows on 2026-10-20 and match on `disasterNumber` plus `applicantId`. CFPB complaints open, but enforcement does not, and there is no shared identifier. FCC plain HTTP is blocked. Grants.gov closeout is an Adobe PDF form, not a row API. NHTSA complaints and recalls both open and share year/make/model, but that direction is not the survivor because the official recalls payload is already the lookup product.

### Cited Findings

- OpenFEMA `PublicAssistanceFundedProjectsDetails` v2 is a daily JSON/CSV/Parquet API. The dataset page, last updated 20 October 2026, lists last data refresh 10-19-2026, 850,184 records, and a CSV and a Parquet file in the 50–500 MB band. It says applicant details come from relating this dataset to Public Assistance Applicants on the Applicant ID field. It also says the dollars are from Grants Manager, not FEMA’s official financial systems, and “this dataset is not intended to be used for any official federal reporting.” — [OpenFEMA Funded Projects Details v2](https://www.fema.gov/openfema-data-page/public-assistance-funded-projects-details-v2)
- A live GET on 2026-10-20 (`$top=1`, rundate `2026-10-20T17:01:41.024Z`) returned `disasterNumber` 4611, `pwNumber` 207, `applicationTitle` “AED Machines”, `applicantId` `089-02058-00`, `damageCategoryCode` E, `projectStatus` Eligible, `projectProcessStep` “Project Closed Out”, `projectSize` Small, `federalShareObligated` 3609, `totalObligated` 3609, `gmProjectId` 552422, `gmApplicantId` 108674, county St. Charles Parish, LA, `lastRefresh` `2026-07-24T15:07:02.020Z`. — [Funded projects API row](https://www.fema.gov/api/open/v2/PublicAssistanceFundedProjectsDetails?$top=1)
- The same `disasterNumber` 4611 and `applicantId` `089-02058-00` on Public Assistance Applicants v1 returned `applicantName` “St. Charles Parish Sheriff's Office”, Hahnville, LA 70057, `lastRefresh` `2026-10-20T15:09:08.919Z`, rundate `2026-10-20T17:04:44.998Z`. Filtering on `applicantId` alone also returned that same applicant id on `disasterNumber` 1380. — [Applicants filtered to disaster 4611](https://www.fema.gov/api/open/v1/PublicAssistanceApplicants?$filter=disasterNumber%20eq%204611%20and%20applicantId%20eq%20%27089-02058-00%27&$top=1); [Applicants filtered on applicant id only](https://www.fema.gov/api/open/v1/PublicAssistanceApplicants?$filter=applicantId%20eq%20%27089-02058-00%27&$top=1)

- Grants.gov post-award reporting forms are downloaded and completed in Adobe Reader, then submitted to the awarding agency. The page does not expose closeout rows as JSON or CSV. — [Grants.gov post-award reporting forms](https://www.grants.gov/forms/forms-repository/post-award-reporting-forms)

- Direct fetch of the NHTSA ODI quarterly-metrics HTML page on 2026-10-20 returned Akamai Access Denied. The complaints and recalls APIs on `api.nhtsa.gov` did not. — [ODI quarterly metrics page](https://www.nhtsa.gov/office-defects-investigation-quarterly-metrics)

### Inferences

- FEMA is the only direction that is both open and joinable on identifiers today. Use the composite `(disasterNumber, applicantId)`. FEMA’s dataset page says to relate on Applicant ID, but the live applicants endpoint returns the same `applicantId` on more than one `disasterNumber`, so Applicant ID alone does not pick one disaster’s projects.
- CFPB “complaints plus enforcement” is not Zetaris-ready. Complaints are ready. Enforcement, as published, is a list of case-page links. Joining “TRANSUNION INTERMEDIATE HOLDINGS, INC.” to a defendant name would be a name match, which the readiness rule rejects.
- FCC is rejected because the official hosts blocked plain HTTP. Do not route around that with a web-unlock vendor. Bright Data is not on the 20 October 2026 sponsor strip.
- Grants.gov closeout/reporting is rejected because the public post-award artifact is an Adobe PDF form. USASpending being up on 20 October 2026 does not supply the SF-425 or the closeout packet.
- NHTSA is technically open and the year/make/model fields are exact, not fuzzy names. It is still the wrong packet to build, for the reason in the next section. `odiNumber` does not appear on the recall payload, and `NHTSACampaignNumber` does not appear as a field on the complaint payload that was opened, so a campaign-number join would be text inside a narrative, not a key.

### Gaps

- The full 850,184-row CSV and Parquet were not downloaded. Only `$top=1` JSON, plus one filtered applicant row, was opened. The record count is from the dataset page, not from a local file count.
- No count of funded projects for applicant `089-02058-00` was taken. One project row was verified.
- `DisasterDeclarationsSummaries` was not opened. It is not needed for the two-table join above.
- No CFPB enforcement JSON or CSV catalog was found on the actions page. A hidden bulk file could still exist; it was not found, and it would still need a shared identifier the complaint hit does not have.
- USASpending was not searched field-by-field for a closeout flag. The public Grants.gov post-award path that was opened is PDF forms, which is enough to reject that direction.
- NHTSA quarterly complaint totals were not confirmed. A direct fetch of the metrics page was denied. Do not use search-index figures for those totals.
- FCC’s Socrata dataset may be public in a browser with a different client. From this environment it did not return rows. Treat it as not ready.

## Which packet does a professional still assemble by hand, and which tools already emit one?

### Takeaway

The packet that is still hand work is a repeat-applicant obligation crosswalk: a county or parish emergency management director, or that office’s Public Assistance applicant agent, lists prior obligated project worksheets for one applicant before anyone types a new claim into Grants Portal. Grants Portal, Veoci, Crisis Track, and FEMA’s own templates emit the current damage file or a blank form. They do not emit a cited list of past `pwNumber`s from OpenFEMA. NHTSA’s open-recall list is already what `recallsByVehicle` returns, so that packet is rejected.

### Cited Findings

- FEMA’s stakeholder tools page points applicants, recipients, and subrecipients to Grants Portal at grantee.fema.gov. The same page offers blank templates and forms, a Cost Estimating Format for large permanent work, equipment rates, and per-capita thresholds. It also links the OpenFEMA applicant and funded-project datasets as statistics, not as a generated memo. The page says it was last updated 9 August 2023. — [PA tools and resources](https://www.fema.gov/assistance/public/tools-resources)
- Veoci’s FEMA Public Assistance product digitizes the current file: category and severity selection, GPS, photos, force-account labor, equipment rates, contractor documents, and “pre-formatted exports” that “match FEMA’s templates” for “portal-ready documentation.” The page does not say it reads OpenFEMA or cites a prior `pwNumber`. — [Veoci FEMA Public Assistance](https://veoci.com/government/fema-public-assistance)
- Juvare Crisis Track is sold to local and state emergency management as field damage assessment that “auto-fills FEMA & FHWA forms,” tracks labor, equipment, and debris, and calculates repair estimates. Its own FAQ says it is for collecting field damage and FEMA reporting. It says it is deployed in 100+ jurisdictions. It does not describe a crosswalk of historically obligated OpenFEMA project worksheets. — [Crisis Track](https://www.juvare.com/crisis-track/)
- OpenFEMA itself is the table of obligated project worksheets, including projects already at “Project Closed Out.” It is not a per-applicant memo. The dataset page links a program-level graphic, “Public Assistance Program Summary of Obligations.” That graphic was not opened, so this note does not claim what it draws for one applicant. — [OpenFEMA Funded Projects Details v2](https://www.fema.gov/openfema-data-page/public-assistance-funded-projects-details-v2)
- Demand, primary source, with a population and a date: FEMA release HQ-25-084, 26 September 2025, says that since 20 January 2025 the administration had provided more than $3.6 billion “to speed up debris removal and fund critical infrastructure projects across the Southeast,” and that more than 107 million cubic yards of debris had been cleared. For Western North Carolina it says FEMA was directed to deliver more than $510 million in Public Assistance grants and an additional $2 billion for debris removal, with more than 15 million cubic yards removed. The same release says FEMA had provided more than $14.3 billion “in flood insurance payments and grants to survivors, communities, states and tribes” for the 2024 hurricane season; that figure mixes programs and should not be quoted as Public Assistance. The release names disasters 4827, 4828, 4829, 4830, 4831, and 4832. — [FEMA HQ-25-084](https://www.fema.gov/press-release/20250926/recovery-continues-after-historic-2024-hurricane-season)
- The NHTSA recalls API, opened the same day as the complaints API, already returns the campaign list for a year, make, and model, including remedy text and `NHTSACampaignNumber`. That is the artifact a recall lookup emits. — [NHTSA recalls by vehicle](https://api.nhtsa.gov/recalls/recallsByVehicle?make=toyota&model=camry&modelYear=2020)

### Inferences

- A hackathon entry that drafts a project worksheet, a damage-assessment PDF, or a Grants Portal submission collides with FEMA’s portal, with Veoci, and with Crisis Track. Those three already aim at the current-disaster form.
- The gap those pages do not claim is historical and cited: for one `applicantId`, list obligated `pwNumber`s, category codes, federal share, and status, joined to the legal applicant name, so a human can decide what not to reinvent on the next disaster. The St. Charles Parish Sheriff’s Office row is a closed small project (PW 207, Category E, $3,609 federal share). A coordinator still has to pull that kind of history by hand from the open data or from old files. None of the four tool pages says it writes that crosswalk.
- Do not let the draft say a project is eligible, reasonable, or replicable. Crisis Track’s marketing says “prove eligibility.” FEMA’s own dataset page says the file is not for official federal reporting. The crosswalk has to stay a draft for the human.
- NHTSA is rejected as the packet. The recalls endpoint already emits the campaign list a service advisor would otherwise copy. A second page that restates `23V865000` next to complaint `11770517` is a lookup demo, which the academy text rules out. CARFAX, URG, and RecallCheck were seen in search results as recall or complaint browsers; those three product pages were not fully fetched, and the rejection does not depend on them.

### Gaps

- No page was found, in the searches run, for a commercial product whose output is specifically an OpenFEMA prior-`pwNumber` crosswalk. That is not a proof that no consultant spreadsheet or state grants system does it inside a login. Grants Portal itself was not logged into. grantee.fema.gov was not opened.
- The obligations visualization linked from the dataset page was not opened.
- MB3 and other state PA systems did not surface as a clean product page in the search that was run. They are not used as evidence either way.
- National Public Assistance obligations for a full fiscal year were not used. A Disaster Relief Fund PDF extract was too poorly parsed to quote. The demand figure above is the 26 September 2025 release, limited to the populations that release names.
- NHTSA competitor pages (CARFAX recall check, URG Recall Program, RecallCheck) were not fully opened. Do not cite them as confirmed product behavior.

## What single idea survives the five-day build?

### Takeaway

Build, in Cursor, a Zetaris-joined draft called a Repeat-Applicant Obligation Crosswalk for a parish or county emergency management director or that office’s Public Assistance applicant agent. Meterless stores one filing constraint and the second draft must change because of it. Quote, in the demo recorded by 27 October 2026, the live identifiers already fetched: disaster 4611, applicant `089-02058-00`, St. Charles Parish Sheriff’s Office, project worksheet 207, GM project 552422.

### Cited Findings

- The two OpenFEMA endpoints above returned matching identifiers on 2026-10-20 for disaster 4611 and applicant `089-02058-00`: applicant name St. Charles Parish Sheriff’s Office; project worksheet 207; title “AED Machines”; category E; status Eligible; process step Project Closed Out; size Small; federal share obligated 3609; GM project id 552422. Project `lastRefresh` was 24 July 2026. Applicant `lastRefresh` was 20 October 2026. — [Funded projects API row](https://www.fema.gov/api/open/v2/PublicAssistanceFundedProjectsDetails?$top=1); [Applicants filtered to disaster 4611](https://www.fema.gov/api/open/v1/PublicAssistanceApplicants?$filter=disasterNumber%20eq%204611%20and%20applicantId%20eq%20%27089-02058-00%27&$top=1)
- The funded-project file is refreshed daily and held 850,184 worksheet rows as of the 10-19-2026 refresh, with the page last updated 20 October 2026. Those closed historical ids will still resolve on 27 October 2026 unless FEMA withdraws the dataset. The demo does not depend on a news cycle. — [OpenFEMA Funded Projects Details v2](https://www.fema.gov/openfema-data-page/public-assistance-funded-projects-details-v2)
- The workload those identifiers sit inside is current through 2025: HQ-25-084 (26 September 2025) documents more than $510 million in Public Assistance grants and an additional $2 billion for debris removal in Western North Carolina, and more than $3.6 billion since 20 January 2025 for Southeast debris and critical infrastructure. — [FEMA HQ-25-084](https://www.fema.gov/press-release/20250926/recovery-continues-after-historic-2024-hurricane-season)
- Grants Portal, Veoci, Crisis Track, and FEMA’s template library cover the live damage file and the blank form. They are the four pages that do not emit this crosswalk. — [PA tools and resources](https://www.fema.gov/assistance/public/tools-resources); [Veoci FEMA Public Assistance](https://veoci.com/government/fema-public-assistance); [Crisis Track](https://www.juvare.com/crisis-track/); [OpenFEMA Funded Projects Details v2](https://www.fema.gov/openfema-data-page/public-assistance-funded-projects-details-v2)

### Inferences

- Five-day slice, 22–27 October 2026. Day 1 (22 Oct): in Zetaris, register only the two GETs that were opened, `v2/PublicAssistanceFundedProjectsDetails` and `v1/PublicAssistanceApplicants`. Join on `disasterNumber` and `applicantId`. Prove it with 4611 and `089-02058-00`. Do not load all 850,184 rows into the demo path; filter. Day 2 (23 Oct): one draft memo, the Repeat-Applicant Obligation Crosswalk, with the applicant legal name, each cited `pwNumber`, `gmProjectId`, category code, `federalShareObligated`, `projectSize`, and `projectProcessStep`, plus the API rundate. A human header names the emergency management director or applicant agent as the reviewer. Day 3 (24 Oct): Meterless H-MEM stores one constraint the human sets, for example “do not carry forward a closed project whose `federalShareObligated` is under 5000,” or “this office will not claim Category B force-account labor.” Run the same applicant again. The second memo must drop or relabel PW 207 and say which stored constraint caused that. No Nemotron, Super VL, or Bolt. Day 4 (25 Oct): a Cursor review screen where the human accepts or edits the constraint. The agent does not submit anything. Day 5 (26–27 Oct): record the demo against the live API and keep disaster 4611, applicant `089-02058-00`, and PW 207 on screen. Stop before 27 October 2026 23:45 UTC.
- Will not build: an eligibility, insurance-offset, procurement, or cost-reasonableness decision; a Grants Portal or Login.gov submission; photo or damage-inventory capture; a Cost Estimating Format workbook; an appeal or arbitration brief; environmental and historic preservation review; a PAPPG chatbot (that guide is a PDF and is not a core source); a full 850,184-row local warehouse; any NVIDIA-class model; any web unlocker; a NHTSA, CFPB, FCC, or SF-425 side path; official federal financial reporting. The memo should repeat FEMA’s own limit: Grants Manager figures can differ from USASpending and are not for official reporting.
- Why this scores: the work is a real pre-filing packet (Impact), the join is two live REST resources on identifiers rather than a banned sample API (Technical and Sponsor tech), the memory change is the difference between run one and run two (Innovation), the demo ids were fetched on 20 October 2026 and are closed projects so they should still be there on 27 October (Demo), and the UX is one reviewer and one memo rather than a chat (Product).
- Rejected directions, with the killing source: CFPB complaints-plus-enforcement, because the actions list is HTML and the complaint hit has no company identifier ([enforcement actions](https://www.consumerfinance.gov/enforcement/actions/), [complaint search](https://www.consumerfinance.gov/data-research/consumer-complaints/search/api/v1/?size=1&no_aggs=true)). FCC robocalls, because plain HTTP returned 403 and Access Denied ([SODA JSON](https://opendata.fcc.gov/resource/vakf-fz8e.json?$limit=1), [help-center API](https://www.fcc.gov/consumer-help-center-api)). USASpending or Grants.gov closeout, because the public post-award forms are Adobe PDFs and the USASpending GET that was opened is only a last-updated date ([post-award forms](https://www.grants.gov/forms/forms-repository/post-award-reporting-forms), [last updated](https://api.usaspending.gov/api/v2/awards/last_updated/)). NHTSA complaints and recalls, because `recallsByVehicle` already emits the campaign list ([recalls by vehicle](https://api.nhtsa.gov/recalls/recallsByVehicle?make=toyota&model=camry&modelYear=2020)).

### Gaps

- It is not known how many worksheet rows `applicantId` `089-02058-00` has. The demo must query that id live and not assume PW 207 is the only line. If a stored “under $5,000” rule removes every line, the second memo should say that in one sentence and cite PW 207 as excluded, not invent another project.
- Whether a state recipient’s internal grants system already prints this crosswalk for Louisiana was not checked. The four public pages above do not.
- The obligations visualization was not opened, so it is not claimed as a competitor and not claimed as a gap-filler.
- No Meterless or Zetaris product page was re-fetched for this note. The memory behavior above is the build constraint (a stored rule changes the next artifact; no local NVIDIA GPU), not a measured vendor benchmark.
